# MedAxis Brand Assets

## Logo variants
- `medaxis-logo.svg` — primary horizontal logo for light backgrounds.
- `medaxis-logo-dark.svg` — primary horizontal logo for dark backgrounds.
- `medaxis-mark.svg` — standalone brand mark.
- `medaxis-mark-dark.svg` — standalone mark for dark surfaces.
- `medaxis-icon.svg` — square app/favicon icon.

## Icon sizes
- 16×16 — browser favicon
- 32×32 — browser favicon
- 48×48 — browser/shortcut icon
- 64×64 — small app/shortcut usage
- 128×128 — launcher usage
- 180×180 — Apple touch icon
- 192×192 — PWA icon
- 256×256 — large launcher usage
- 512×512 — PWA/app icon

The SVG master icon is scalable and is used for all declared sizes where a raster asset is not required.

## Brand colors
- Deep Navy: `#0D1B2A`
- Primary Teal: `#005F6B`
- Slate Gray: `#64748B`
- Light Background: `#F2F5F9`
